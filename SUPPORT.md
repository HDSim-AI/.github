# Support

## Something is broken

Open an issue in the repository it affects:
[hdsim](https://github.com/HDSim-AI/hdsim/issues) for the method core,
[travel-decision](https://github.com/HDSim-AI/travel-decision/issues) for trips,
[residential-mobility](https://github.com/HDSim-AI/residential-mobility/issues) for move-or-stay.
Say what you ran and what happened; verbatim output beats a description of it.

## You want to add a decision domain

Start with [CONTRIBUTING.md](https://github.com/HDSim-AI/hdsim/blob/main/CONTRIBUTING.md), which
routes by what you are trying to do. `examples/minimal_domain.py` is a complete domain in one file
and runs with no API key, so you can see the shape before committing to anything.

## You want to talk it through first

Email mustafasameen@ufl.edu. We would rather have the conversation than have you guess.

## You want to understand the method

The paper is [arXiv:2604.10475](https://arxiv.org/abs/2604.10475). The
[live demo](https://yushundong.github.io/pemand_simulation/pemand_official_site.html) replays six
household scenarios in the browser with no setup.
